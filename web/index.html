M5 HW ID

Flash this on any M5 board (ESP32 or ESP32-S3). It auto-detects silicon, M5 board id, display size, and I2C devices — then prints a factual report on the screen and USB serial.

Manifest must be valid JSON: ./firmware/manifest.json

What you get
  • Chip model, revision, flash, PSRAM, MAC
  • M5Unified board id + name (AtomS3R, Core2, …)
  • Display resolution
  • I2C map (LP5562, BMI270, ES8311, AXP, …)
  • Suggested firmware target hint

Open serial at 115200 after flash. Press the button to reprint the report.
